# Agent RSI 精读论文分类

本文索引与 Agent RSI 方案最直接相关的十篇论文。分类依据是论文最适合被借鉴的研究环节；部分论文横跨多个方向。

## 内部状态与因果机制

目录：`内部状态与因果机制`

1. **From Latent Signals to Reflection Behavior**  
   按层和生成阶段追踪反思状态，分析 latent-control、semantic-pivot 和 overt behavior 的形成过程。
2. **Triggering Chain-of-Thought via Latent Feature Interventions**  
   使用 SAE 发现推理相关特征，通过注入和抑制检验充分性与必要性。
3. **Hidden Error Awareness**  
   区分可被 Probe 读取的诊断信号与真正能控制行为的因果表示。
4. **Mechanistic Interpretability of Chain-of-Thought Reasoning via Sequential Activation Patching**  
   将单点 activation patching 扩展到连续 Token 和多 Attention Head。

## 失败归因与表示学习

目录：`失败归因与表示学习`

1. **A Mechanistic Study of Automated Failure Attribution in LLM-based Agentic Systems**  
   研究模型内部是否已经编码了失败责任步骤，以及内部知识与显式归因之间的差距。
2. **ReCast**  
   通过层选择、pattern/deviation 特征、对比学习和排序目标学习归因导向的步骤表示。

## Harness 与持久修复

目录：`Harness与持久修复`

1. **AutoSaddler**  
   从失败轨迹进行深度诊断，生成结构化 Harness 补丁，并通过验证选择持久更新。
2. **RESKILL**  
   显式维护失败假设、候选补丁、覆盖关系和重测结果组成的 repair state。
3. **Evo-Harness**  
   将单次长上下文中的经验编译成可跨任务复用的 Skill Harness。

## 泛化与持续学习

目录：`持续学习视角`

1. **Self-Evolving Agents Can Repair Failures but Struggle to Generalize from Them**  
   区分原任务修复和未见任务泛化，揭示 failure-only evolution 的 repair-generalization gap。

该目录还保留 **Are Self-Evolving Agents Continual Learners**，用于从持续学习角度理解自演化系统，但不计入上述十篇核心精读清单。

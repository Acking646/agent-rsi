# Agent RSI 精读论文分类

本索引按研究问题分类，而不是按会议分类。PDF 均放在对应目录；同一论文只保留一份。更新日期：2026-11-19。

## 内部状态与因果机制

目录：`内部状态与因果机制`

1. **From Latent Signals to Reflection Behavior**：按层追踪 latent-control、semantic-pivot 与 overt behavior，适合作为“前缀语义—内部状态—显式行为”分阶段因果链模板。
2. **Triggering Chain-of-Thought via Latent Feature Interventions**：用 SAE 发现候选特征，通过 steering 与 suppression 分别检验充分性和必要性。
3. **Hidden Error Awareness**：证明 Probe 可读信号不等于模型实际使用的因果信号，是机制实验的关键负面对照。
4. **Mechanistic Interpretability of Chain-of-Thought Reasoning via Sequential Activation Patching**：将 patching 扩展到连续 token 和多 attention head，适合长反思前缀。
5. **The Curse of Multiple Mediators**（arXiv:2606.27510）：指出单组件 activation patching 会混入组件交互效应，要求同时报告 single、sequential 与 joint patching。
6. **Is This the Subspace You Are Looking For?**（arXiv:2311.17030）：说明成功改变输出的子空间干预也可能激活非自然备用通路，不能仅凭可控性声称机制忠实。
7. **Towards Best Practices of Activation Patching**（arXiv:2309.16042）：系统比较 corruption、metric 与 patching 设置，作为实验规范依据。

## 失败归因、信用分配与表示学习

目录：`失败归因与表示学习`

1. **A Mechanistic Study of Automated Failure Attribution in LLM-based Agentic Systems**：发现 knows-but-won't-say gap，并用 locator-head 到 writer-head grafting 改变归因输出；最适合扩展为归因激活到更新提案 writer 的桥梁。
2. **ReCast**：通过层选择、pattern/deviation 特征、对比学习和排序目标学习归因导向表示，是 Linear Probe 之上的强表示基线。
3. **My FAULT: Self-Diagnosis as Credit Assignment in Self-Evolving Agentic Reinforcement Learning**（arXiv:2610.01161；ICLR 2027 当前 3/3/4）：把经过检查的自然语言诊断转成由终局结果约束的步骤级信用。
4. **AgentRx**：从完整执行轨迹诊断 Agent 失败。
5. **Executable Prefix Values for Locating Agent Failures**：利用可执行前缀价值定位失败位置。
6. **Who and When Pro**：评估模型能否正确识别责任 Agent 与决定性步骤。
7. **Why Do Multi-Agent LLM Systems Fail / MAST**：提供多 Agent 失败类型与轨迹分析框架。

以下三篇 ICLR 2027 匿名投稿尚未发现公开 arXiv 版本，OpenReview 当前要求浏览器验证，因此暂登记链接，未把验证页面伪装成 PDF：

- **Counterfactual Supervision for Credit Assignment in Language Model Agents**，OpenReview `QzGGstYqbH`，当前 3/3/3。恢复动作前状态，比较原动作与同策略替代动作的执行结果，为步骤信用提供反事实标签。
- **Self-Improvement Needs Attribution: Dependency-Aware Causal Memory for Long-Horizon Mobile GUI Agents**，OpenReview `nBLZ51xxGn`，当前 2/3/4。连接依赖归因、因果上下文与经验更新。
- [OpenReview 链接：Counterfactual Supervision](https://openreview.net/forum?id=QzGGstYqbH)；[Self-Improvement Needs Attribution](https://openreview.net/forum?id=nBLZ51xxGn)。

## Harness、上下文与持久修复

目录：`Harness与持久修复`

1. **AutoSaddler**：从失败轨迹深度诊断，生成结构化 Harness 补丁，并通过开发集选择持久更新。
2. **RESKILL**：显式维护失败假设、候选补丁、覆盖关系和重测结果组成的 repair state。
3. **Evo-Harness**：将单次嘈杂执行上下文编译成跨任务复用的 Skill Harness。
4. **Context Language Models**（arXiv:2609.37725；ICLR 2027 当前 4/4/4）：把上下文作为模型可编辑文件，为前缀的精确、可重复干预提供系统实现。
5. **LongHarness**（arXiv:2610.13075；当前 2/4/4）：分离 EvidenceBank 与 Conclusion State，并让未解决结论驱动检索。
6. **GUI-HARVEST**（arXiv:2610.00948；当前 2/3/3/4）：比较同任务重复执行，先记录预期行为变化，再验证有界 Harness 代码编辑。
7. **Harness Annealing**（arXiv:2610.01235；当前 3/3/3）：逐步撤除 Harness 支持，检验外部控制职责能否被模型内部化。
8. **Learning from Research / ScholarEvolve**（arXiv:2609.40169；当前 3/3/4）：按 Harness 模块检索论文、生成 mutation blueprint、实现候选并联合验证。
9. **GEPA**（arXiv:2507.19457；ICLR 2026 Oral）：用自然语言反思生成 prompt 更新，在 Pareto frontier 上选择和合并候选，是文本反思基线。
10. **AEL、Living-Harness、Harness Updating Is Not Harness Benefit**：分别覆盖开放式 Harness 演化、持续运行更新以及更新能力与收益的解耦评价。

## 轨迹技能与记忆

目录：`轨迹技能与记忆`

1. **ReasoningBank**：把成功和失败轨迹蒸馏成可检索策略记忆。
2. **MemGen**（arXiv:2509.24704；ICLR 2026 Poster）：由 memory trigger 监测推理状态，再由 memory weaver 生成 latent memory token，是内部状态到外部记忆行为的重要邻近方法。
3. **SkillForge、SKILLREVISE、When Not to Imitate、Agent Skills Can Be Harmful**：覆盖成功/失败边界、技能修订、拒绝模仿和技能副作用。
4. **Information-Constrained Memory Evolution**，OpenReview `6co6OsqoT3`，当前 3/3/4：限制编辑器从重复反馈任务获得的信息容量，降低记忆更新过拟合。该匿名投稿尚无公开 arXiv PDF，暂登记 [OpenReview 页面](https://openreview.net/forum?id=6co6OsqoT3)。

## RSI 环境、开放式演化与评价风险

目录：`RSI环境与开放式演化`

1. **RSI-Env、RSI-Bench、Darwin Gödel Machine**：分别提供开放式环境、RSI 评价和开放式代码演化背景。
2. **MetaExp**（arXiv:2610.21492；ICLR 2027 当前 3/3/4）：用 Shared-Tool 与 Shared-Workflow 任务族训练跨任务经验学习能力，适合检验更新知识是否真正可复用。
3. **False Frontiers**（arXiv:2609.39102；当前 3/3/3）：揭示 proposer 与 solver 可能共同形成错误闭环，要求使用独立来源和外部正确性验证。

## 泛化、持续学习与风险

目录：`持续学习视角`

1. **Self-Evolving Agents Can Repair Failures but Struggle to Generalize from Them**：区分原任务修复与未见任务泛化，揭示 repair-generalization gap。
2. **Are Self-Evolving Agents Continual Learners**：从持续学习角度定义自演化系统的知识保留、迁移和遗忘。
3. **Your Agent May Misevolve**（arXiv:2509.26354；ICLR 2026）：比较模型、记忆、工具和工作流演化路径，并评估 misevolution 与安全漂移。

## 与当前方案最直接的精读顺序

1. A Mechanistic Study of Automated Failure Attribution
2. Counterfactual Supervision for Credit Assignment in Language Model Agents
3. From Latent Signals to Reflection Behavior
4. Hidden Error Awareness
5. Triggering Chain-of-Thought via Latent Feature Interventions
6. Sequential Activation Patching
7. My FAULT
8. ReCast
9. The Curse of Multiple Mediators
10. False Frontiers

前三层判据必须分开报告：**可解码（encodable）**、**干预后提案改变（behaviorally used）**、**执行提案后未见任务改善（improvement-effective）**。
